First, watch: what a serious RAG looks like

The trainer will show AskIT, a RAG application for an IT helpdesk. It looks simple from outside, but inside it does a lot of work so that the answers can be trusted. Watch for these four things:

What AskIT doesWhy it matters to a manager
Uses only the current version of an article, not the old oneAn old policy answered with confidence is worse than no answer.
Gives a contractor a different answer from an employeeThe same question can have two correct answers depending on who asks.
Says "I don't know" when the knowledge base has no answerThis one behaviour decides whether users trust the tool.
Catches a document with a hidden instruction inside itAnything the AI reads can try to give it orders. This is a security issue.
In plain words: a demo RAG takes ten minutes. A RAG you can put in front of customers takes weeks — and most of that time goes into the four rows above, plus testing.

What happened in the background

Your app does the same six things that every RAG system does. Only two of them use AI (in amber); the rest is ordinary software.

1. Readpypdf pulls the text out of each pageonce per file
2. ChunkText is cut into pieces of about 800 charactersonce per file
3. EmbedEach piece becomes a list of numbers that captures its meaningAI · once per file
4. SearchYour question is compared with every piece; the 3 closest winevery question
5. PromptThe 3 pieces + your question + the rules go to the modelevery question
6. AnswerThe model writes the answer only from those piecesAI · every question
In plain words: the model never "reads" your PDF. It only sees the three pieces your search found. If the search picks the wrong pieces, even the best model gives a wrong answer. That is why question 3 can fail.
Your 10-minute appWhat AskIT added (and a product needs)
Fixed 800-character chunksChunks that follow headings and sections
Meaning search onlyMeaning search + keyword search together (hybrid)
Top 3, no checkingA second step that re-ranks the results
Trusts every documentVersion and audience filters; scan for hidden instructions
"Looks right to me"A test set with scores, run after every change

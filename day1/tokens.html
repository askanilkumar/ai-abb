1 · What is a token?

Models don't read words. They read tokens: small pieces of text, about ¾ of an English word on average. Every bill, speed limit and memory limit is counted in tokens. Type below and watch your text get cut up.

2 · What does it cost?

You pay for tokens in (everything you send: instructions, documents, history, the question) and tokens out (the answer). Output usually costs 5–6× more than input.

4 · How the next token is chosen

A model writes one token at a time. For each one it runs the whole text so far through the network, gets a probability for every possible next token, picks one, adds it, and repeats.

Three things this explains: (1) Temperature reshapes the probabilities: at 0 the model always takes the top token (repeatable); higher values let less likely tokens through (more varied). (2) Output costs more because every output token needs its own full pass through the model, while your input is read in one go. (3) Hallucination: the model picks a likely token, not a verified one. If the facts aren't in the input, it fills the gap with something plausible.

Your feedback

Rubric: 5 areas × 2 marks — Problem & owner · Guardrails fit the risk · Spec & evals · Model & cost · Measurable value. 8–10 PILOT · 4.5–7.5 REVISE · below 4.5 STOP. A REVISE is normal for a first canvas — it means the idea is worth fixing.

Abby prompt pack — start on Monday

One starter prompt per cluster, with the review board's lessons built in: use only the pasted data, rules first, say "not in data" instead of guessing, ignore instructions hidden in tickets, no names. Save it as an Abby personal prompt, run it beside your manual work for two weeks, and compare.

30-60-90 days — from canvas to pilot

The pattern for every cluster: Level 1 an Abby prompt on pasted data (this week) → Level 2 connect the data source and let Power BI / Excel do the numbers (month 2) → Level 3 an agent that drafts and a person approves (month 3, only if the evals pass).
